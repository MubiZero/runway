# Pass 1b: System & Pilot Defect Classes (8 Classes)

Complements [pass-1-defects.md](pass-1-defects.md) with the 8 system-level classes that break real pilots:

1. **Data Integrity & Migrations:** Multi-step writes without a DB transaction; missing DB constraints (`UNIQUE`, `FOREIGN KEY`, `CHECK`); irreversible or unverified migrations; untested backups. *Fix:* Wrap multi-step writes in transactions, enforce constraints in DB, lint migrations with `postgres-migrations` (`check_migration.sh`), and test backup restore on a clean instance (G9).
2. **Offline, Sync & Race Conditions:** Assuming constant connectivity; check-then-write without row locking or `ETag`/version checks; ordering events by client wall-clock time. *Fix:* Outbox queue with idempotency keys, optimistic concurrency (`version`/`ETag`) or `SELECT ... FOR UPDATE`, server timestamps, and visible `"Offline: N actions queued"` status (G7).
3. **Resource Budgets:** Unmeasured cold start, RAM growth over 1 hour, idle CPU, startup request waterfall, or bundle size; leaked timers/subscriptions; aggressive polling instead of SSE/WebSocket. *Fix:* Set budgets in `RELEASE.md`, measure on target hardware, fix subscription leaks in shared hooks/controllers (G6).
4. **Install, Update & Rollback:** Undocumented manual install steps, non-atomic updates, no checksum/signature verification, no visible app version in UI/logs, or no rollback path. *Fix:* Verify clean install, upgrade preserving data, and rollback on the target OS (G1/G2).
5. **Security & Authorization:** UI-only permission checks (hidden button, open API endpoint), IDOR (fetching/mutating another tenant's ID), missing login/OTP rate limits, secrets in repo/client bundle, SQL/shell string concatenation, debug endpoints in prod builds. *Fix:* Enforce tenant/role checks on every server handler, rate-limit auth, parameterize queries, scan with secret checks (G8).
6. **Observability:** Swallowed errors, missing correlation/request IDs, PII in logs, or no way for pilot support to see why a client machine failed yesterday. *Fix:* Structured logs with request IDs, crash reporting, and a one-click diagnostic bundle (G10).
7. **Dependencies & Supply Chain:** Unpinned versions, missing lockfile, abandoned packages, or critical CVEs. *Fix:* Commit lockfiles, run `govulncheck`/`osv-scanner`/`npm audit`, replace trivial 5-line dependencies with stdlib (G8).
8. **Configuration & Environments:** Hardcoded URLs/flags, silent crashes on missing env vars, or risk of pointing a local/pilot build at production DB. *Fix:* Single config loader with startup validation, safe defaults, and clear environment separation.
